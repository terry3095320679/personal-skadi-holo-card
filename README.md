## 项目说明

- 此仓库是个人练习和同人展示，**不是工作项目，也不是鹰角网络或《明日方舟》的官方项目**。
- 游戏名称、角色及相关视觉元素的权利归其原权利人所有。本页面不用于商业销售。
- `index.html` 为可独立打开的展示文件；仓库不含账号凭据或开发环境文件。
- 交互效果基于 [LerSent001/holo-card](https://github.com/LerSent001/holo-card) 的本地工作流制作。第三方说明见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。

## 浏览方式

打开上方在线链接即可在手机或电脑查看。手机可触摸拖动旋转、点按翻面；方向传感器效果取决于浏览器支持与授权。
